Add El Cid Handicaps to Home Screen

Add a shortcut to your device's home screen for quick access. This website cannot create the shortcut automatically; follow the steps for your device.

iPhone or iPad (Safari)

  1. Open this website in Safari.
  2. Tap the Share button (the square with the upward arrow).
  3. Scroll down and tap Add to Home Screen. If it isn't visible, check the options in the Share menu.
  4. Tap Add to Home Screen.
  5. (Optional) If the “Open as Web App” toggle is visible, slide it off so it opens as a standard browser bookmark.
  6. Tap Add to finish.

Android (Chrome)

  1. Open this website in Chrome.
  2. Tap the three-dot menu in the upper-right corner.
  3. Choose Add to Home screen or Install app, if offered.
  4. Follow the prompts to add it.

Tip: If the option is missing, make sure you're viewing the live website in the recommended browser rather than inside another app.
